`sample-security.evtx` is a clean, 7-record Windows Security event log from the
public test corpus of the `evtx` Rust parser:
https://github.com/omerbenamram/evtx/tree/master/samples

The parser project and its sample data are dual-licensed under MIT or
Apache-2.0. The file was downloaded from:
https://raw.githubusercontent.com/omerbenamram/evtx/master/samples/Security_short_selected.evtx

It contains Security event IDs 5152, 4611, 4776, 4625, 5157, and 4673. This is
clean parser test data; use the in-app synthetic sample report to explore AuthLens
detection examples.
